# Animated People Controller
Warning
`Omni.Anim.People` is being deprecated in the next release and we are replacing it with a better system. We strongly recommend that you revise all code that used `omni.anim.people` as soon as possible.`Omni.Anim.People` is the underlying Extension for simulating human behaviors for Isaacsim.Replicator.Agent (IRA) . It is driven by Behavior Script , which subscribes to USD stage events and reacts to them.Refer to IRA Character Behaviors for more information.
