# Application Template
Isaac Sim can also be installed and customized via the application template repo . This repository allows you to build lightweight apps that pull extensions from the registry directly. We provide a set of default applications that mirror the main Isaac Sim binary application configs as well as a set of templates that can be customized and extended for your own applications.
For more details and a quick start guide see here .
