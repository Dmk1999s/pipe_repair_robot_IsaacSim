# Third-Party SimReady USD Assets
Isaac Sim welcomes open source assets from the community. This page outlines links to third-party assets that are compatible with Isaac Sim.

[TABLE]
Link | Description
Lightwheel SimReady store | Catalog of open sourced and closed source environments and prop assets.
X-Humanoid ArtVIP Dataset | A large-scale dataset of articulated 3D objects and scenes.
Synthesis Asset pack | A collection of assets for synthetic data generation.
SpatialVerse dataset | InteriorAgent, InteriorGS, InteriorAgent_Nav datasets for synthetic data generation.
XGrid Scan to Simulation Tutorial | Tutorial for converting a 3D scan to a simulation environment in NVIDIA Isaac Sim.
MolmoSpaces | A large-scale dataset with articulated 3D objects and diverse indoor scenes.
[/TABLE]
