# Replicator Menu
The Replicator (Tools > Replicator) menu has a suite of useful tools and extensions for omni.replicator and generating, visualizing, and recording synthetic data.

[TABLE]
UI Element | Reference
Semantics Schema Editor | Add semantic information. Refer to the Semantics Schema Editor docs for more details.
Synthetic Data Recorder | Synthetic Data Recorder. Refer to the Synthetic Data Recorder docs for more details.
ReplicatorYAML | Generating dataset using Replicator YAML .
Start | Starts the randomizations and writing to disk omni.replicator .
Step | Performs a single randomization operations with writing to disk omni.replicator .
Preview | Performs a singe randomization iteration without writing to disk omni.replicator .
[/TABLE]
