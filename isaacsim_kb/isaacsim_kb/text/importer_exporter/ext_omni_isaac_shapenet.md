# ShapeNet Importer
Warning
[DEPRECATED]: omni.isaac.shapenet is deprecated. You can import ShapeNet models as you would any other OBJ file.
The ShapeNet Importer Extension allowed import and conversion of 3D models from the ShapeNet V2 database into Omniverse as USD files.
