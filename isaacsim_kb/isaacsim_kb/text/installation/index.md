# Installation
Isaac Sim installation is available for Windows and Linux. It can be installed in a container, on a workstation, in the cloud, via livestream, or in a Python environment. Your hardware setup can also be customized depending on how you intend to use Isaac Sim.
The quick install is the easiest way to get started. It walks you through the installation of Isaac Sim for Windows or Linux and shows you how to create a basic room with a robot arm on a table.
