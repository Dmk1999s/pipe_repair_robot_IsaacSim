# FAQ
GeneralIs there a way to use Isaac Sim without an internet connection?
Yes. Download the Latest Release of Isaac Sim Assets Packs. See Local Assets Packs to run local assets.
Is there a way to use Isaac Sim without downloading it locally?
Yes. See Cloud Deployment
PerformanceIsaac Sim is loading very slowly.
The first time you open NVIDIA Isaac Sim, it may take a while for the materials to compile.
If a large asset is loading very slowly, it is likely that the materials are compiling. This should happen only on first load of the asset.
See Location for Isaac Sim shader cache for location of the local shader cache.
For more information, see Workstation Installation for how to install.
Isaac Sim is running very slowly.
To speed up the simulation, you can reduce the complexity of the scene and robot, such as reducing the number of joints and links, simplify collision geometry and texture. You can also modify simulation step settings. For more information, see Isaac Sim Performance Optimization Handbook .
