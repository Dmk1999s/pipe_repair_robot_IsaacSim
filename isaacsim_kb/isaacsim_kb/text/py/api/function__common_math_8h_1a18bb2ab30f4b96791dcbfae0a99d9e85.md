# Swap
template<typenameT>
inlinevoidSwap(T &a, T &b)

Swaps two values.
Template Parameters:
T – Type of the values to swap

Parameters:

- a – [inout] First value (will contain b after swap)

- b – [inout] Second value (will contain a after swap)
