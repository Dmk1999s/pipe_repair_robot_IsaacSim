# ATan2
inlinefloatATan2(floatx, floaty)

Computes the arc tangent of y/x using the signs to determine quadrant.
Returns the angle from the positive x-axis to the point (x, y)
Parameters:

- x – [in] X coordinate

- y – [in] Y coordinate

Returns:
Arc tangent of y/x in radians, in the range [-π, π]
