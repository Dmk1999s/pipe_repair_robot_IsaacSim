# Determinant
inlinefloatDeterminant(constMatrix22 &m)

Calculates the determinant of a 2x2 matrix.
Computes the determinant using the standard formula: det(m) = m(0,0) * m(1,1) - m(1,0) * m(0,1)
Parameters:
m – [in] Matrix to compute determinant for

Returns:
Determinant value of the matrix
