# RotationMatrix
inlineMatrix22 RotationMatrix(floattheta)

Creates a 2D rotation matrix for the given angle.
Constructs a rotation matrix that rotates points counter-clockwise by the specified angle in radians. The matrix has the form: | cos(θ) -sin(θ) | | sin(θ) cos(θ) |
Parameters:
theta – [in]Rotation angle in radians

Returns:
2x2 rotation matrix
