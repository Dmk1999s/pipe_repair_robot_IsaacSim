# Trace
inlinefloatTrace(constMatrix22 &a)

Calculates the trace of a 2x2 matrix.
The trace is the sum of the diagonal elements: trace(a) = a(0,0) + a(1,1)
Parameters:
a – [in] Matrix to compute trace for

Returns:
Trace (sum of diagonal elements) of the matrix
