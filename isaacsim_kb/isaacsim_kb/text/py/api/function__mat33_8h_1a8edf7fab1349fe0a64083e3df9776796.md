# Diagonalize
inlineMatrix33 Diagonalize(constVec3 &v)

Creates a diagonal matrix from a 3D vector.
Off-diagonal elements are set to zero
Parameters:
v – [in] Vector containing diagonal elements

Returns:
Diagonal matrix with v.x, v.y, v.z on the diagonal
