# L2_magnitude
inlinefloatL2_magnitude(constMatrix33 &matrix)

Computes the L2 magnitude (Frobenius norm) of a matrix.
Computes the square root of the sum of squares of all matrix elements
Parameters:
matrix – [in] Matrix to compute magnitude for

Returns:
L2 magnitude of the matrix
