# ExportMeshToBin
voidExportMeshToBin(constchar*path, constMesh *m)

Exports a mesh to binary format.
Saves mesh data in a flat binary format for efficient storage and loading.
Parameters:

- path – [in] File path where the binary mesh data will be saved

- m – [in] Pointer to the mesh to export
