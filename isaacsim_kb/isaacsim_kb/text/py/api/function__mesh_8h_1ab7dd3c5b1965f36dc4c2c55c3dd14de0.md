# CreateEllipsoid
Mesh *CreateEllipsoid(intslices, intsegments, Vec3 radiis)

Creates an ellipsoid mesh primitive.
Generates an ellipsoidal mesh with different radii along each axis.
Parameters:

- slices – [in] Number of longitudinal slices

- segments – [in] Number of latitudinal segments

- radiis – [in] Radii along X, Y, and Z axes

Returns:
Pointer to the created ellipsoid mesh
