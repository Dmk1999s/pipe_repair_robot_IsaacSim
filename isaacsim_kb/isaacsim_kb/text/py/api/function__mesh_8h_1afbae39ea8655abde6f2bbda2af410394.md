# CreateTetrahedron
Mesh *CreateTetrahedron(floatground=0.0f, floatheight=1.0f)

Creates a tetrahedron mesh primitive.
Generates a tetrahedral mesh with specified ground level and height.
Parameters:

- ground – [in] Ground level Y-coordinate (default: 0.0)

- height – [in] Height of the tetrahedron (default: 1.0)

Returns:
Pointer to the created tetrahedron mesh
