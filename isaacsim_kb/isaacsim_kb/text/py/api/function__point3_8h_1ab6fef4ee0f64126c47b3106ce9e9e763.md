# operator-
inlineVec3 operator-(constPoint3 &lhs, constPoint3 &rhs)

Computes the vector from one point to another.
Parameters:

- lhs – [in] The starting point.

- rhs – [in] The ending point.

Returns:
A Vec3 representing the displacement from lhs to rhs.
