# Cross
inlineVec3 Cross(constVec3 &b, constVec3 &c)

Computes the cross product of two 3D vectors.
Returns a vector perpendicular to both input vectors following right-hand rule
Parameters:

- b – [in] First vector

- c – [in] Second vector

Returns:
Cross product vector (b × c)
