# operator==
template<typenameT>
booloperator==(
constXVector3 <T >&lhs,
constXVector3 <T >&rhs,
)
Equality comparison operator for vectors.
Template Parameters:
T – Numeric type of vector components

Parameters:

- lhs – [in] First vector to compare

- rhs – [in] Second vector to compare

Returns:
True if all components are equal, false otherwise
