# pose
namespacepose

Utilities for handling pose transformations in USD scene graphs.
Provides functions for computing and manipulating poses (transforms) in USD scenes. Handles both world-space and local-space transformations, supporting:

- World transform computation without caching

- Relative transform computation between prims

- Support for both USD and USDRT stages

- Automatic handling of position, orientation, and scale
