# Isaac xPrim Axis Visualizer Node
displays the x,y,z axis of an xPrim for visualization.

## Installation
To use this node enable isaacsim.util.debug_draw in the Extension Manager.

## Inputs

[TABLE]
Name | Type | Descripton | Default
Exec In ( inputs:execIn ) | execution | The input execution port | None
Length ( inputs:length ) | float | Length of the axis lines | 1
Thickness ( inputs:thickness ) | float | Thickness of the axis lines | 1
xPrim ( inputs:xPrim ) | target | Usd prim to visualize | None
[/TABLE]
