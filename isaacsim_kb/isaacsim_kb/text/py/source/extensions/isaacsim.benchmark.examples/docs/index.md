### Extension Settings
The table list the extension-specific settings.

[TABLE]
Setting name | Description | Type | Default value

scene_path | Path to the scene to load, for example “/Isaac/Environments/Grid/default_environment.usd”. If empty, no scene is loaded. | str | ''
